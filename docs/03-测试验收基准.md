# 性能基准 / QA 证据 / 发布验收规范

> 生成日期：2026-08-21 ｜ 团队：testing-performance-benchmarker / testing-evidence-collector / testing-reality-checker

## 1. 性能/画质基准方案（performance-benchmarker）

### 1.1 指标集
| 类别 | 指标 | 工具 |
|---|---|---|
| 帧时 | avg / P95 / P99 / 1%low / 0.1%low / 卡顿数 | PresentMon（ETW）+ CapFrameX + RTSS |
| GPU | Busy%、占用、频率、功耗 | PresentMon / HWiNFO64 |
| VRAM | 已用/峰值、带宽 | HWiNFO64 |
| 帧生成延迟 | Presented vs Displayed 帧差（DLSSG 必须用 `--displayed`，否则帧时虚低） | PresentMon / FrameView / LDAT |
| 画质主观 | 锐度/鬼影/闪烁/边缘抖动/伪影 1–5 分 | OBS 无损录制 + 同帧截图 |

依据：`hooked_present` 不改 Present 语义（`Dx11FsrBridge.cpp:6018`），PresentMon 数据可信；每 5s `fsr2_runtime_status`（candidates/dispatches/failures/shim_queries，`:6010-6014`）作功能红线。

### 1.2 场景矩阵
- 场景（每段 30s 固定镜头/路径）：①静止全景 ②跑图（直线+转向）③群怪战斗 ④固定副本 ⑤角色技能/大招（覆盖 TAAU 临时路径，`ini:36-40`）。
- 因子：HDR 开/关；渲染精度 0.5/0.75/1.0；后端 FSR2 / 原生 TAAU（`Fsr2TranslationMode=0` 对照）/ FSR3 / FSR4；DLSSG 开/关。
- **最小回归集** = {①③⑤}×{0.5,1.0}×{FSR2, 原生TAAU}×{HDR 开/关}；扩展集加 FSR3/FSR4 与 DLSSG。
- 风险专项镜头（曝光/FOV/平方解码）：昼夜切换、大俯仰视角、快速横向甩镜。

### 1.3 控制变量与流程
- 固定：角色、位置、游戏内时钟/天气、分辨率/画质档、HDR、驱动、游戏版本、桥接+后端提交、`package.ini` 全量开关指纹。
- 预热 60s（shader 编译 + FSR2 历史收敛）；≥3 次重复 × ≥30s 稳定段（~1800 帧@60fps），丢弃前 10s。
- CSV 列：`timestamp,frame,frameTimeMs,gpuBusyPct,vramMB,backend,renderScale,hdr,dlssg,scene,run`。

### 1.4 回归阈值与红线
- P95 ≤ A+5% 或 +2ms（取大）；1%low 恶化 ≤8%；平均劣化 ≤3%；卡顿数不增；VRAM 峰值增量 ≤+200MB；GPU Busy 上升 >5% 需书面说明。
- 画质：鬼影/闪烁/伪影主观分不得下降 ≥1 分。
- **红线**：`fsr2_translation_failure_count=0`、`shim_queries mask=0x3F` 稳定、`detoured=1`；任何 failure>0 或 mask 漂移 = FAIL。

## 2. QA 证据采集规范（evidence-collector）

### 2.1 截图/录屏
- 固定相机/游戏内时间；一律无损 PNG；录屏用无损/近无损编码。
- HDR：固定 SDR/HDR 输出路径，关闭系统 Auto-HDR/驱动色调滤镜（Bridge 有 `tone_map_hdr_backbuffer_to_sdr`，`:6017`）；HDR 下另截 SDR 映射基准。
- A/B 并排同帧输出，标注档位与分辨率。

### 2.2 日志采集清单
| 文件 | 位置 | 关键行 |
|---|---|---|
| Dx11FsrBridge.log | DLL 同目录（`:11113`） | `mask=0x3F`（:10944）；`exports=6`（:11171）；`detoured=1`（:9476-9480）；`dispatch_failed code=`（:9487）；`fsr2_runtime_status` 每 5s（:6010-6014） |
| AntiPlayerMosaic.log | DLL 同目录（`:578`） | `resolved: rva=`（:478-480）；`scan failed: matches=N`（:472）；`patched PlayerPerspective/DiveMosaic`（:408/:427） |
| 特征缓存 | 模块同目录 | `Dx11FsrBridge.features.cache`、`AntiPlayerMosaic.features.cache` |

- 三日志无内置时间戳 → 以「进程启动时刻 + 文件首行 + 修改时间」对齐，用事件顺序而非壁钟。
- 判定值：`mask=0x3F`=6 个 FSR2 导出查询全命中；`detoured=1`=双入口判定 Hook 已接管（`Fsr2TranslationLayer.cpp:802-808`）。

### 2.3 崩溃证据包
WER/事件查看器 XML（Faulting module/ExceptionCode/Offset）+ `%LOCALAPPDATA%\CrashDumps\` dump + 复现步骤模板（环境快照→操作序列→预期 vs 实际→复现率）；「复现后勿再启动游戏」以免覆盖日志。

### 2.4 问题报告必填
游戏版本（含 `pe_timestamp`/`image_size`，`:11162-11163`）、显卡+驱动、OptiScaler 版本（≥0.10.0-pre1 支持帧生成）、加载顺序、DLL 构建类型（Release/Debug）、配置项（OptiScaler.ini LogLevel/超分模式/HDR）、四件日志。

### 2.5 证据等级（验收门槛）
- L0 描述（不可采信）→ L1 单证（截图或日志）→ **L2 可复现截图+日志（issue 关闭门槛，可重复≥2 次）** → L3 双端并排对比。
- mask/detoured/签名匹配数必须出现在日志证据内，不能仅凭截图推断。

## 3. 发布验收（reality-checker）

### 3.1 结论
**主干当前不可发布（NEEDS WORK）**；reality-checker 独立复核了全部关键发现（已证实清单见 `01-FSRBridge-全面审查报告.md`），并修正：`Fsr2ResetOnColorPathChange` 在**发布构建默认=1**（`#if DX11FSRBRIDGE_RELEASE_RUNTIME` `:3347-3348`），S2「默认不 reset」仅对非发布构建成立。

### 3.2 验收清单
**Blocking（禁发）**
- B1=C1 vtable 槽位 39→40（`:94`、`:10591`）；验收：DLSSG DX11-on-12 路径 ResizeBuffers1 不再误入 4 参钩子，无崩溃。
- B2=H1 vtable 克隆按实际槽数；验收：ID3D11Device(42 槽) 克隆无越界，ASan/AppVerifier 通过。
- B3=供应链信任链（自更新 digest 带外来源 + vendored SHA256 清单）；验收：模拟代理篡改包体时自更新必须中止。

**Should（随正式版）**
- M1 竞态、M2 无界增长、M3 clamp、S1 曝光、S2 修正后重验。

**Could**
- S3 jitter cancellation、ini RVA 死配置清理。

### 3.3 发布流程建议
- **hotfix v1.2.4**：仅 C1+H1 + 回归测试（内存安全止血）。
- **v1.3**：Should/Could 全清单，逐项按上述验收标准走 CI + 实机回归。
- 发布前：重生成 vendored SHA256 清单、修正 README「无需更新也能支持新版本」表述（过度承诺，改「已适配 7.0，新版本需重新验证」）、按修正后的 S2 前提重测。
